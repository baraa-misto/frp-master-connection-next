# Private Reference Area

This directory is an optional local holding area for authorized, privately licensed engineering sources. Its contents are ignored by Git except for this README.

Do not place a source here unless the user is licensed and local handling is authorized. Never commit ASCE/SEI 74-23 PDFs, equations, tables, figures, commentary, extended excerpts, or other copyrighted/private content. The Stage 0.1 repository does not require the standard PDF; the registered errata set remains verification pending.
