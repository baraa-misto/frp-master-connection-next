# FRP Master Connection — Stage 3.5A Beam-to-Concrete Wall Using Symmetric Paired FRP Clip Angles — Authority Ledger RC1

## New authority

Stage 3.5A authorizes one new Shear Connections product:

`FRP W/I Beam -> Symmetric Paired FRP Clip Angles -> Concrete Wall`

It authorizes:

- one horizontal W/I beam;
- two identical mirrored FRP clip angles;
- one common beam-web through-bolt group;
- two identical mirrored wall-anchor groups;
- one finite concrete wall support;
- one signed vertical reaction shear;
- exact branch split under the accepted Stage 3.3B symmetry proof;
- exact wall-interface wrench translation and summation;
- one external anchor-design handoff.

## Shear-only boundary

The user applies vertical reaction shear only.

Stage 3.5A does not authorize:

- user-applied moments;
- axial beam force;
- horizontal wall shear;
- out-of-plane force;
- torsion;
- moment-resisting classification.

Exact moments generated by translating the shear force between physical reference points remain mandatory in the external anchor handoff.

These transfer moments do not constitute moment-connection design.

## Pair-sharing authority

The Stage 3.3B exact pair/action symmetry proof remains controlling.

RC1 locks identical mirrored angles, identical mirrored wall-anchor groups, centered beam geometry, symmetric materials, and eligible pure reaction shear.

No new load-sharing equation is introduced.

## Concrete-wall authority

The concrete wall is authoritative only for:

- physical surface/frame;
- finite geometry;
- anchor coordinates;
- geometric containment;
- specified coordination embedment;
- geometric edge distances;
- load-transfer reference points;
- visualization.

No concrete resistance or adequacy is calculated.

## External anchor authority

The application may represent and geometrically validate an externally designed anchor layout.

It shall issue an immutable handoff containing:

- combined wall wrench;
- positive/negative group wrenches;
- anchor coordinates;
- wall frame;
- geometric edge distances;
- nominal anchor/hole geometry;
- specified embedment;
- units/sign convention;
- fingerprints.

The application shall not issue:

- anchor steel capacity;
- concrete breakout;
- pullout;
- pryout;
- side-face blowout;
- seismic qualification;
- concrete edge/spacing capacity;
- concrete member capacity.

## Demand boundary

The accepted Stage 2.5A demand engine may be used for:

- common beam group demand;
- exact branch/group equilibrium;
- nominal wall-anchor point demand trace for FRP-side coordination.

Nominal anchor-point demands are not anchor-system design results.

Specialized anchor-design software governs external anchor demand/capacity verification.

## Resistance boundary

No new resistance equation is introduced.

Existing accepted beam-side and FRP-side checks may execute only where their current applicability contracts hold.

Required external/design limitations include:

- `CONCRETE_SUBSTRATE_RESISTANCE = EXTERNAL_DESIGN_REQUIRED`;
- `ANCHOR_SYSTEM_RESISTANCE = EXTERNAL_DESIGN_REQUIRED`;
- `ANCHOR_STEEL_RESISTANCE = EXTERNAL_DESIGN_REQUIRED`;
- `ANCHOR_CONCRETE_LIMIT_STATES = EXTERNAL_DESIGN_REQUIRED`;
- `EXTERNAL_ANCHOR_DEMAND_VERIFICATION = REQUIRED`.

Existing paired-angle limitations remain.

Ordinary whole-connection PASS is prohibited.

Known supported numerical failure retains FAIL precedence.

## Geometry and hardware authority

Beam-side common bolts use the existing controlled ASTM F593 system.

Wall anchors use separate external-anchor geometry and presentation.

Blind embedded anchors shall not be rendered with fictitious far-side wall hardware.

One anchor shank per anchor axis.

## Frozen-family boundary

No existing Direct, Tee, Clip-Angle, or Multi-Member Tee engineering fingerprint may change.

Stage 2.3, Stage 3.2, Stage 3.3, and Stage 3.4 freeze tags remain immutable.

## Explicit exclusions

Stage 3.5A does not authorize:

- anchor/concrete design;
- anchor product selection;
- adhesive design;
- through-wall bolts;
- single clip angle;
- unequal angle pair;
- unequal wall groups;
- other beam profiles;
- user moments;
- moment connection;
- column base;
- direct side-lap wall connection;
- import of external anchor-software results.

**END OF AUTHORITY LEDGER RC1**
