## 1. Purpose

C2-P2 defines a second isolated stainless connector-body calculation slice for **hole-free clear rectangular plate strips under already-resolved axial force and/or in-plane bending moment**.

It adds no public stainless family capability.

## 2. Material and numerical constants

Use the frozen C2-M record:

- material family: `316 Stainless Steel`;
- initial numerical basis: `GENERIC_316SS_CONSERVATIVE_BASIS_US_SOURCE`;
- `Fy = 25 ksi`;
- `Fu = 70 ksi`;
- `E = 28,000 ksi`;
- no MTR overstrength;
- no cold-work strength credit;
- no CSM strength enhancement.

Native exact quantity conversions remain mandatory. No C2-P2-specific conversion constants are permitted.

## 3. Product/fabrication scope

Included:

- unwelded A240/A480 plate/sheet/strip;
- cut/drilled/machined body;
- qualified hole-free clear rectangular strip.

Excluded:

- angle/Tee/form-shape resistance;
- welded or laser-welded built-up shapes;
- cold-formed strength credit;
- local fold/weld-junction checks.

## 4. Geometry/reference frame

For the selected clear strip:

- `x` = longitudinal force-path axis;
- `y` = in-plane transverse plate-width axis;
- `z` = through-thickness axis;
- `b` = physical clear width in `y`;
- `t_nom` = nominal plate thickness;
- `t` = frozen C2-P1 design thickness.

The provider shall retain the actual section boundaries and the source of `b`; it shall not infer a Whitmore/effective width from bolt patterns.

## 5. Section properties

For the rectangular cross-section normal to `x`:

`A = b t`

`Iy = b t^3 / 12`

`Iz = t b^3 / 12`

`ry = t / sqrt(12)`

`rz = b / sqrt(12)`

`Sy = b t^2 / 6`

`Sz = t b^2 / 6`

`Zy = b t^2 / 4`

`Zz = t b^2 / 4`

C2-P2 in-plane moment is `Mz` only.

## 6. Design thickness

Reuse the frozen C2-P1 B4.2a rule exactly:

- `t_nom > 3/16 in` -> `t = t_nom`;
- `t_nom <= 3/16 in` -> `t = 0.95 t_nom` unless trusted tolerance authority qualifies nominal credit.

No new thickness policy is introduced.

## 7. Required trusted plan inputs

At minimum retain:

- frozen material/source identity;
- nominal and design thickness;
- clear-section identity and boundaries;
- clear width `b`;

- local reference frame and sign convention;

- flexural `Lb`;

- family-activation false;
- source/method/provider version.

Client-entered capacities, arbitrary section properties, arbitrary K, or arbitrary favorable Cb are not engineering authority.

## 8. Clear-body qualification

The section is eligible only when all are true:

- no hole intersects the critical section;
- no net-section/flexural-rupture hole case is needed;
- no local bolt bearing/tearout zone governs the requested check;
- no weld/fold/formed-angle/Tee junction lies in the strip;
- no transverse concentrated load, prying, or contact reaction requires a local plate mechanism;
- no material-dependent response needs to be generated by this provider.

Otherwise return a fail-closed applicability status and no P2 capacity for the unsupported method.

## 9. Compression

### 9.1 Resistance factor

`phi_c = 0.90`.

### 9.2 Flexural buckling

For each required principal flexural-buckling axis:

`Fe = pi^2 E / (Lc/r)^2`.

Use AISC 370 Table E3.1 Curve A:

`alpha = 0.56`

`beta0 = 0.76`

`beta1 = 0.41`

`beta2 = 0.69`

Branch rules:

- **yield plateau**:
  if `Lc/r <= beta0 sqrt(E/Fy)`, `Fn = Fy`;

- **inelastic buckling**:
  if `beta0 sqrt(E/Fy) < Lc/r <= 5.62 sqrt(E/Fy)`,
  `Fn = 1.2 * beta1^((Fy/Fe)^alpha) * Fy`;

- **elastic buckling**:
  if `Lc/r > 5.62 sqrt(E/Fy)`,
  `Fn = beta2 Fe`.

Then:

`Pn = Fn A`

`Pc = phi_c Pn`.

Evaluate both supplied principal flexural-buckling axes. Minimum `Pc` governs.

### 9.3 Effective length

`Lc = K L` only when `K` and `L` are trusted resolved stability inputs.

C2-P2 shall not infer K from connection topology, bolts, contact, or appearance.

### 9.4 E4 gate

A compression check is numerical only when trusted authority states:

`E4_DISPOSITION = QUALIFIED_NOT_CONTROLLING`

If E4 is required or unresolved, emit the applicable fail-closed status and do not report a compression capacity.

## 10. In-plane flexure about z

### 10.1 Resistance factor

`phi_b = 0.90`.

### 10.2 Yielding/plastic endpoint

`Mp = Fy Zz`

`My = Fy Sz`.

### 10.3 LTB parameter

`q = Lb b / t^2`.

### 10.4 Branches

If:

`q <= 0.306 E/Fy`

then:

`Mn = Mp`.

If:

`0.306 E/Fy < q <= 2.00 E/Fy`

then:

`Mn = min[ Cb (1.61 - 0.36 q Fy/E) My, Mp ]`.

If:

`q > 2.00 E/Fy`

then:

`Fcr = 1.78 E Cb / q`

`Mn = min(Fcr Sz, Mp)`.

Finally:

`Mc = phi_b Mn`.

All branch values and governing reason shall be traceable.

## 11. Cb authority

If no trusted favorable moment-gradient profile exists:

`Cb = 1.0`.

If trusted profile authority supplies Cb:

- it shall be traceable to the F1 moment-profile rule or an approved equivalent;
- `Cb` shall not exceed `1.67`;
- a favorable client-entered scalar does not qualify.

The fingerprint binds the actual credited `Cb` and its authority disposition.

## 12. Combined axial compression + in-plane flexure

Initial interaction method is H2 in lieu of H1:

`IR = Pr/Pc + |Mr|/Mc`.

Numerical result:

- `PASS` when `IR <= 1.0`;
- `FAIL` when `IR > 1.0`.

The provider shall not replace unresolved `Pc` or `Mc` with infinity/zero/defaults.

## 13. Combined axial tension + in-plane flexure

Both H2 checks are required.

Tension-side yielding interaction:

`IR_t = |Mr|/Mct + Pr/Pct`.

Compression-side/flexural interaction:

`IR_c = |Mr|/Mc - Pr/Pct`.

Where:

- `Pct` is the same-section frozen C2-P1-compatible available tensile strength for the qualified full-direct-transfer, hole-free section;
- `Mct = 0.90 Fy Sz`;
- `Mc` is the C2-P2 F9 available flexural strength.

Both equations shall be retained. Governing interaction is the larger ratio.

Do not credit H1 tension Cb amplification in RC1.

## 14. Pure axial tension

C2-P2 does not replace C2-P1 pure tension.

If `Mr = 0` and axial force is tensile, the ordinary C2-P1 tension route remains the resistance authority.

## 15. Raw eccentricity prohibition

C2-P2 does not calculate a moment from raw eccentricity.

An input containing `P` plus `e`, but no upstream-resolved `M` with provenance, returns:

`STAINLESS_ECCENTRIC_MOMENT_NOT_RESOLVED`.

Resolved `P` and `M` may be consumed regardless of how an authorized upstream solver obtained them.

## 16. Shear and torsion boundary

C2-P1 remains pure-shear resistance authority.

Initial C2-P2 does not authorize a combined `N-M-V` interaction rule.

If nonzero shear is simultaneous with axial force and/or in-plane moment in a request that requires combined qualification, return:

`STAINLESS_COMBINED_NORMAL_SHEAR_NOT_SUPPORTED_IN_C2_P2`.

Any nonzero torsional resultant returns:

`STAINLESS_TORSION_NOT_SUPPORTED_IN_C2_P2`.

## 17. Unsupported flexural directions

Return fail-closed for:

- nonzero `My` out-of-plane/minor-axis plate bending;
- biaxial bending;
- unknown moment axis.

Initial statuses:

`STAINLESS_OUT_OF_PLANE_FLEXURE_NOT_SUPPORTED_IN_C2_P2`

`STAINLESS_BIAXIAL_FLEXURE_NOT_SUPPORTED_IN_C2_P2`.

## 18. CSM boundary

Appendix 2 CSM shall not be invoked by C2-P2 RC1.

A request for CSM/strain-hardening strength credit returns:

`STAINLESS_CSM_NOT_SUPPORTED_IN_C2_P2`.

This does not prohibit future separately approved advanced-method work.
