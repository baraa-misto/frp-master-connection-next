## Physical topology

One new product, `WI_RHS_SRS_COLUMN_MOMENT_BASE_CONNECTION`, contract `4.5-RC1`.
WI12, RHS8, RHS10X8, SRS8 and SRS10X8 each support TWO_X,TWO_Y,FOUR_XY.
Each connector retains its own dimensions and source records. Positive-face
controls own the shared physical grid, shank diameter/thread and hardware;
the opposite A direction and tangential center are mapped, not copied as signs.
The opposing angle's thickness and foot geometry remain independent.

W/I TWO_X traverses ANGLE/WEB/ANGLE once. W/I TWO_Y has two independent short
ANGLE/SELECTED_FLANGE groups. Hollow full-through paths retain the two actual
walls and free-shank cavity; the cavity never enters the resistance-layer ledger.
Solid paths retain continuous solid material without a virtual thin wall.
FOUR_XY composes these pairs. Default X rows are2/4in and Y rows5/7in;
no edit silently shifts another pair. Default physical member shanks: W/I4/8/12
and RHS/SRS4/4/8 for TWO_X/TWO_Y/FOUR_XY respectively; foundation groups8/8/16.

Native profile/region APIs resolve centroids, slab/wall geometry and R14B bases.
Existing full-through builders, containment and exterior hardware functions are
used. The new adapter adds only global placement and finite cardinal-segment
clearance checks. Shared hardware has one physical ID and distinct physical
layer/analytical connector identities. Internal RHS nuts/washers, sleeves,
cavity fill, backing plates and fictitious reinforcement are not introduced.
A centered single W/I flange bolt at the web is invalid; an explicit owner
tangential relocation can make it valid. It is never relocated automatically.

## Numerical and source contracts

Global inputs are (Vx,Vy,N),(Mx,My,0) at the actual column-end centroid.
N positive is uplift; N negative is compression. Placement generates the exact
reference-shifted Mz at foundation O. Required total foundation action and its
opposite reaction are reported once, independent of unresolved branch response.
Direct column-end pressure is a separate contact contribution, not another
copy of total N. Connector foot actions already include their own foot contact.

The new response validator consumes a geometry/material/fixture/reference-bound
qualified record: two/four complete branch wrenches, actual ordered per-layer
bolt actions, actual shaft cuts, source-authorized layer couples/secondary
bending, normal/prying/contact basis, real compression-only contact patches and
exact whole-base equilibrium. It does not solve load sharing or stiffness.
Source records keyed by physical ID are canonically enumerated; the ordered
material layers and shaft cuts are NOT reordered. Duplicate/missing/unknown
IDs, wrong references, unauthorized couples, inconsistent sections, fabricated
wall participation and false contact activity fail closed. All source capacities
remain separate from demand/response qualification.

For each available branch, accepted Calculation Slice7
`resolve_angle_connector` transports the full six-component member/heel/foot
wrenches. Accepted Slice8 `calculate_in_plane_wrench_demand` receives exact
physical bolt coordinates and the full local (FA,FB,MC) reference. Its native
result is retained verbatim as an in-plane reference candidate, never overlaid
on a source's coupled physical bolt response. FC,MA,MB remain explicit. A one-bolt
nonzero free-moment reference remains natively unsupported, even if a separately
qualified coupled response includes secondary-bending couples.

Existing native profile Decimal authority, quantity conversion, core rational
proofs and Slice8 Decimal80 projections are unchanged. Native projected engine
outputs are not independently regenerated or normalized. Reference fixtures are
independent rational bookkeeping checks only, never serialized-value replacements.
No tolerance, residual redistribution, equivalent eccentricity for a free moment,
or M/z-only force decomposition is used.

## Applicable design checks and explicit limitations

Only explicit Run Design Check invokes resistance. Preview invokes no resistance
provider or capacity equation. Production qualified registries are empty; typed
source text cannot install synthetic/manufacturer qualification.

Accepted Slice7 FRP instep scope and qualified full-wrench body/source checks
are reused. Member attachment uses a separate full-wrench qualified capacity
binding. Actual source-bound shaft cuts use native bolt shear, tension and sourced
interaction functions, without capacity multiplication. ASTM F593 identification
does not supply numerical strength.

Actual LW/CW signed layer forces use R14B bases: column LW vertical; angle LW
horizontal extrusion. Native single-lap bearing is dispatched only when a short
W/I flange interface and actual constant cardinal response establish applicability.
Native connector first-row/inter-row paths require the actual qualified constant
extrusion-directed forces to match the inherited in-plane candidate exactly;
nonstandard holes and oblique/heel-directed/coupled paths retain explicit limits.
Native pull-through uses actual exterior terminal washers and both native branches;
no internal hollow washer or solid-thin-plate shortcut is used. Qualified common
column-end-zone coverage must cover all unresolved local paths, junctions, wall
participation, local bending/solid-region and combined interaction scopes.

Evaluated failures outrank missing capacities, with actual failed-check IDs and
subordinate source limitations retained. No ordinary whole-base PASS is allowed.
Concrete/anchors/foundation strength, full column design, stiffness/rotation and
full-strength classification remain external/not evaluated.
