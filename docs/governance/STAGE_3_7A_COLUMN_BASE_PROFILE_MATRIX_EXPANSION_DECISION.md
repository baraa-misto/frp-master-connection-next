# FRP Master Connection — Stage 3.7A Column-Base Profile Matrix Expansion — Decision

## Decision

Stage 3.7A is a controlled successor to the frozen Stage 3.5 concrete-support shear family.

It expands the existing shear-category column-to-concrete base-angle connection from W/I columns to this matrix:

| Column profile | Single base angle | Double base angles |
| --- | --- | --- |
| W/I | Existing / preserve | Existing / preserve |
| Rectangular Hollow Section (RHS) | Add | Add |
| Solid Rectangular Section (SRS) | Add | Add |
| Angle column | Add | Add |

Normal product label:

**Column connection — Single/double base angles to concrete**

The product remains under **Shear Connections**.

No user-applied moment is added. All moments generated by physical eccentricity remain mandatory.

## Frozen Stage 3.5 boundary

The Stage 3.5 freeze tag remains immutable:

`stage-3.5-concrete-support-shear-family-freeze`

→ `7bb83e5c8814781419c0789b7428bd46572d514c`.

Historical Stage 3.5C / R1 / R2 W/I behavior and fingerprints remain exact.

Stage 3.7A introduces an additive successor contract.

## Generic frame and actions

Use one right-handed local connection frame:

- `L_C`: column longitudinal axis, positive upward;
- `T_C`: outward normal of the selected column connection surface / selected Angle-leg plane;
- `S_C`: in-plane horizontal axis such that `S_C × T_C = L_C`.

Normal current inputs:

- signed Axial force `P_L` along `L_C`;
- signed Connection-plane shear `V_S` along `S_C`;
- signed Connection-normal shear `V_T` along `T_C`;
- zero user-applied moment.

For historical W/I behavior:

- `S_C` maps to web-plane shear;
- `T_C` maps to web-normal shear.

## Action reference

The member action is applied at the backend-authoritative column member-end reference.

For W/I, RHS, and SRS this is on the centroidal longitudinal axis.

For an Angle column, use the actual backend-authored Angle-section centroid/member reference.

Do not move the action reference to the selected leg to remove eccentricity.

If the repository does not expose a trustworthy backend Angle centroid/member reference, STOP before mutation and request separate reference-axis authority.

## W/I topology — unchanged

### Single
One base angle on one selected broad face of the W/I web.

### Double
One base angle on each broad face of the same W/I web.

Preserve Stage 3.5C symmetry and load-allocation behavior exactly.

## RHS / SRS selected face

For rectangular columns, allow the existing four exterior faces supported by the shared rectangular-profile authority.

The backend derives:

- selected face;
- exact opposite face;
- local frame;
- physical through-bolt path.

## RHS single

One base angle against the selected RHS exterior wall.

Full-through physical bolt:

`Base-Angle Vertical Leg -> Near RHS Wall -> Hollow Cavity -> Far RHS Wall`

Hardware:

- head/washer exterior to connector;
- nut/washer exterior to opposite wall;
- no internal hardware;
- cavity is free shank only.

## RHS double

One identical base angle on the selected face and one on the exact opposite face.

Common physical through-bolt:

`Positive Base-Angle Vertical Leg -> Near RHS Wall -> Hollow Cavity -> Far RHS Wall -> Negative Base-Angle Vertical Leg`

No internal hardware.

## SRS single

One base angle against selected SRS face.

Physical bolt:

`Base-Angle Vertical Leg -> Solid Rectangular Column`

with external head/washer and opposite exterior nut/washer.

## SRS double

One identical base angle on selected and opposite faces.

Physical bolt:

`Positive Base-Angle Vertical Leg -> Solid Rectangular Column -> Negative Base-Angle Vertical Leg`.

No fictitious cavity.

## Angle-column selected leg

The user selects exactly one Angle-column leg using existing repository identity:

- Leg Y; or
- Leg Z.

Both broad faces of that selected leg are physical candidate connector faces.

The other column leg remains in the physical geometry and interference model.

## Angle-column single

One base angle on one selected broad face of the selected column leg.

Physical bolt:

`Base-Angle Vertical Leg -> Selected Angle-Column Leg`

with external head/washer and opposite-face nut/washer.

Reject heel / perpendicular-column-leg / connector interference without automatic repositioning.

## Angle-column double — shear-family topology

Double means:

**one base angle on each broad face of the same selected Angle-column leg**.

Common physical bolt:

`Positive Base-Angle Vertical Leg -> Selected Angle-Column Leg -> Negative Base-Angle Vertical Leg`.

This is the only Angle-column Double topology in Stage 3.7A.

## Future Angle-column moment topology — excluded

The following is not Stage 3.7A:

- one connector on column Leg Y;
- another connector on column Leg Z;
- explicit moment-couple design.

Required scope identity:

`ANGLE_COLUMN_TWO_DIFFERENT_LEGS_MOMENT_BASE = NOT_IN_STAGE_3_7A_SCOPE`.

Reserve that topology for future **Moment Connections** work.

## Signed axial component-demand philosophy

Preserve the accepted owner philosophy.

### Column
The column local transfer/member region is independently assigned 100% of the signed axial action.

Design magnitude:

`|P_L|`.

Material axial direction:

`LW`.

### Base-angle system
The base-angle connector system is independently assigned 100% of the same signed axial action.

Base-angle vertical-leg material axial direction:

`CW`.

These are serial component adequacy demands and never double the physical foundation reaction.

Existing physical-path/layer demand allocation remains controlling; do not invent new RHS-wall or solid-body sharing fractions.

## Single system

Single base angle receives the full connector-system action.

Exact generated eccentricity moments remain in the anchor/foundation handoff.

## Double system — complete branch sharing

Complete 50/50 branch sharing requires exact geometry and action symmetry.

### W/I
Preserve Stage 3.5C behavior.

### RHS / SRS
For exact selected/opposite-face mirrored geometry with centroidal member reference, identical connectors/anchors/materials, `V_T=0`, and zero user moment, authorize exact 50/50 branch sharing.

### Angle column
Geometric symmetry of connectors about the selected leg does not prove action symmetry because the Angle centroid is generally offset from that selected-leg plane.

Do not infer a complete 50/50 branch wrench merely from connector geometry.

Retain the exact total base-angle-system/foundation wrench.

The common Plate/Leg/Plate in-plane layer allocation may still use exact `0.5 / 1.0 / 0.5` provenance for the supported in-plane bolt-group demand after local connector/leg symmetry proof.

Required limitation when complete branch allocation is not proven:

`ANGLE_COLUMN_BASE_ANGLE_BRANCH_WRENCH_ALLOCATION = NOT_EVALUATED`.

## Connection-normal shear

`V_T` acts along the column/base-angle bolt axes.

No automatic bolt-axis tension/prying solution.

Complete branch allocation is not authorized for Double when `V_T != 0`.

## Rectangular full-through layers

Reuse shared frozen full-through architecture.

### RHS
- near wall = material;
- cavity = `FREE_SHANK_SPAN`;
- far wall = material;
- no cavity material axes/resistance layer.

### SRS
- one continuous solid material path;
- no cavity.

No duplicate physical bolt.

No internal hardware.

## Material axes

Preserve backend-authored bases.

At minimum:

- column axial action = LW for W/I, RHS, SRS, Angle;
- selected wall/leg retains region LW/CW/TT;
- base-angle vertical-leg axial transfer = CW;
- base-angle horizontal-leg region axes remain backend-authored;
- RHS cavity has no axes;
- concrete has no FRP axes.

## Compression / uplift

Preserve Stage 3.5C-R2 convention:

- `P_L > 0` = uplift/tension;
- `P_L < 0` = compression;
- `P_L = 0` = no axial action.

Compression retains unresolved direct-column-end versus base-angle bearing partition as external where applicable.

Uplift does not use direct column-end bearing.

Anchor tension/concrete uplift remain external.

## Exact foundation reaction

Physical foundation action is counted once.

Never sum the column 100% adequacy demand and base-angle-system 100% adequacy demand into a doubled reaction.

## Engineering limitations

Preserve existing Stage 3.5C limitations and add profile-specific limitations only where genuinely needed.

At minimum retain:

- concrete/anchor capacity external;
- base-angle body/heel limitations;
- uplift prying limitation;
- connection-normal bolt-axis response limitation;
- Angle-column complete branch-wrench allocation limitation when action symmetry is absent.

Supported numerical failure retains FAIL precedence.

No ordinary unqualified whole-connection PASS is created across required unevaluated/external states.

## No new resistance equation

Stage 3.7A is a topology/profile/action-reference expansion.

Reuse accepted:

- Stage 2.5A group demand;
- Stage 2.5B resistance handoff;
- full-through rectangular architecture;
- Stage 3.5C/R2 component-demand semantics;
- existing local FRP checks;
- existing bolt resistance only where already authorized.

Do not create a new material/resistance equation merely to support a new profile.
