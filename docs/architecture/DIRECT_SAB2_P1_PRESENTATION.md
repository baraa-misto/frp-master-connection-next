# Direct SAB2-P1 presentation boundary

P1 changes the current Direct viewer, Materials/Conditions presentation and
signed-report readability. The backend F9 decision remains the status authority.
The viewer reads its analytical maximum and matching evaluated check only when
the design, material/input key and signed report session are current. It does not
envelope scenarios, calculate a resistance/demand or alter a snapshot.

Geometry-only, invalid, checking, error and stale states display neutral gray with
no utilization. An incomplete supported result retains the backend YELLOW; a
backend RED retains RED. Independent bolt ratios are explicitly identified when
FRP material applicability stops the FRP resistance checks.

Reports keep physical dimensions separate from native template diagnostics.
Signed significant-digit formatting never hides a small nonzero clearance or
changes its raw fit state. Component tags reuse native identities and projections;
moment tables display the existing reference-transport diagnostic only. Both
Supporting W block paths retain their native check IDs and unresolved method state.
The audit adds exact field/check locators and wraps complete native values while
preserving the existing attachment, bookmarks and signed calculation authority.

All 53 protected engineering identities and 173 historical control identities
remain unchanged. No calculation, geometry, material policy, qualification,
snapshot/authentication boundary, dependency lock or coverage exclusion changes.
I14, LV1-N01, U02 and C13-05/06/07/08 remain outside P1. Owner acceptance is pending.

The P1 governance manifest records the added 90F/140F signed PDF controls and actual
test counts. Its reverse-delta verifier reconstructs the exact SAB2 workflow and
every predecessor gate. Full local scripts and all four hosted jobs must pass with
exact configured 100% coverage before review readiness is reported.
